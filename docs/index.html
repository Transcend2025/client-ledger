What it does

Reads the lines you already write - 09:00-10:30 @Acme design review, 45m @Acme sync, 22:30-00:30 @Acme migration. A line is billable only with both a duration and a client.
Dashboard, invoice, timesheet Tracked vs billable time per client, a markdown invoice note, a printable HTML invoice, and a CSV timesheet with date, start, end, hours, rate, amount.
Never over-bills a typo 09:00-09:00 reads as 24 hours. It is excluded from every total and printed on the invoice under “Not billed — needs review”, with the original line and file.
Honest about what it can't bill Notes with no date in the file name are never billed; an audit command lists them and every timed line that has no client yet.
